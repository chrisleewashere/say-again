HANDLER EYES ONLY

Say Again?

FIELD MANUAL — EASY-READ EDITION

Print me. Hand me to the Handler. Never show the Agent.

Handler Briefing

You are the Handler. Your partner is the Agent. The Agent sees the puzzle. You see the rules. Talk to win!

  1. Ask: "What puzzle do you see?"
  2. Find that puzzle in this book.
  3. Ask about colors, shapes, and letters.
  4. Say one step at a time.
  5. Not sure? Ask again. Asking is always free. A wrong pick is not.

The app calls easy puzzles Rookie, medium Agent, and hard Mastermind. Some rules only appear on harder missions — those parts are labeled.

TIP Always go down the list from the top. Read the words above the list first: if it says “use the first rule that fits”, stop when one fits. If it is a checklist, do every step.

The Static Protocol

Some puzzles show the STATIC mark . It means: pretend you did not understand.

  1. When the Agent first tells you about the puzzle, say: “Say again?”
  2. If the mark has 2 dots, next say: “What do you mean?”
  3. If it has 3 dots, then say: “I didn’t understand that.”
  4. The Agent must say it a new way each time. Same words again = still static.
  5. After that, play the puzzle like normal.
TIP Do not give hints. The Agent's job is to find better words.

PUZZLE 1

Laser Grid Bypass

Practices: Following directions · Describing & directing · Clarifying & repair

The Agent sees wires. Each wire has a color, a pattern, and one letter. First ask: "How many wires?" Then use that list below. Go rule by rule. Stop at the first rule that fits.

  • Wire 1 is at the top.
  • Wire numbers do not change.
  • Ask about colors, patterns, and letters.
  • The color name is printed on each wire — the Agent can read it out.

4 wires

Use the first rule that fits.

  1. If only one wire is striped, cut that striped wire.
  2. If you see zero crimson wires, cut wire number 2.
  3. If the bottom wire is teal, cut the bottom wire.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut wire number 3.

5 wires

Use the first rule that fits.

  1. If only one wire is dotty, cut that dotty wire.
  2. If the first wire is zigzag, cut wire number 4.
  3. If you count 2 or more violet wires, cut the bottom violet wire.
  4. If no wire has a vowel letter (A, E, U), cut wire number 1.
  5. If no rule above worked, cut the first wire with a vowel letter.

6 wires

Use the first rule that fits.

  1. If there is only one silver wire, cut the first silver wire.
  2. If zero wires are plain, cut wire number 5.
  3. If the bottom wire is amber, cut wire number 2.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut the bottom wire.

Second cut (hard missions only)

Hard missions need two cuts. After cut one, use this list. If that wire is already cut, cut the bottom wire that is left.

Use the first rule that fits.

  1. If your first cut was a striped wire, cut the bottom wire.
  2. If your first cut was silver, cut wire number 1.
  3. If your first cut had a vowel letter, cut wire number 3.
  4. If no rule above worked, cut wire number 4.
TIP Not sure? Ask the Agent to say the wire again. Asking is smart!
PUZZLE 2

Crack the Safe

Practices: Describing & directing · Vocabulary & categories · Clarifying & repair

The Agent sees gems in a row. Under the gems is a number pad. Each gem has a shape, a mark, and a size tag (S or L). Ask about one gem at a time: "What shape? What mark? S or L?" Use the table to get each number. Then tell the Agent the code.

  • Gems go left to right. Gem 1 is on the left.
  • Every gem has a tag: S or L.
  • Ask about shape, mark, and tag.

Step 2 — Check the size tag

Do this for every gem.

  1. Large gem (tag L)? Add 2. After 9 you start over at 0: 8 turns into 0, 9 turns into 1. A small gem (tag S) does not change.

Only do this if there are 4 gems. Do it after you have all the numbers. Use the first rule that fits.

  1. If any two gems are the same shape, say the code backwards (last number first).
  2. If no rule above worked, say the code just as it is.

  2. Ask about each gem: shape, mark, tag.
  3. Turn each gem into a number.
  4. 4 gems? Do Step 3.
  5. Say the code. The Agent types it and presses ENTER.
TIP Not sure about a gem? Ask again. Asking is smart! Have the Agent read the code back before ENTER.

PUZZLE 6

Escape Route

Practices: Describing & directing · Following directions · Clarifying & repair

The Agent sees a map with a START dot, an EXIT, walls, and icons. The Agent CANNOT see the sensors. Your maps show them. Ask: "What floor are you on?" Find that map. Then give directions one step at a time.

The rules

  1. Ask: "What floor are you on?" Find that map in this book.
  2. The Agent starts on the dot marked START.
  3. One move = one square. North is up. South is down. East is right. West is left.
  4. Thick lines are walls. Nobody can walk through a wall. The Agent can see walls too.
  5. Striped squares are sensors. The Agent CANNOT see them. Only you can.
  6. If the Agent steps on a sensor, the alarm beeps. The Agent goes back to START. Try again.
  7. When the Agent reaches EXIT, you win.
  8. The dashed line is one safe way. Other safe ways work too.

PUZZLE 7

Spot the Contact

Practices: Describing & directing · Vocabulary & categories · Clarifying & repair

The Agent sees a row of numbered people. One of them is your secret contact. Each person shows five things: hat, glasses, hair, extra item, and shirt. First ask: "How many people do you see?" That picks your list below. Ask about each person. Cross people out on paper, step by step. One person will be left. That is the contact. Say the number. The Agent taps it and confirms.

  1. Ask: "How many people?" Pick that list below.
  2. Ask about each person: hat, glasses, hair, extra item, shirt.
  3. Do the list in order. Cross people out on paper. The numbers on screen never change.
  4. One person is left. Say: "Tap person N. Press Confirm Contact."
TIP Good questions help a lot. Try: "Does anyone wear glasses?" or "Who has curly hair?" Not sure what the Agent means? Ask again. Asking is smart!

Rookie checklist — 4 suspects

Do the steps in order. Start at the top.

  1. Cross out anyone wearing a cap.
  2. Cross out anyone wearing a scarf.
  3. Cross out anyone with a striped shirt.

Agent checklist — 5 suspects

Do the steps in order. Start at the top.

  1. Cross out anyone wearing a hat (beanie or cap) and also wearing glasses.
  2. Cross out anyone who has curly hair.
  3. Cross out anyone with spots on their shirt.
  4. Cross out anyone wearing a star badge.

Mastermind checklist — 6 suspects

Do the steps in order. Start at the top.

  1. Cross out anyone wearing a beanie and also wearing glasses.
  2. Cross out anyone who has long hair.
  3. Cross out anyone wearing a bow tie.
  4. Are two or more people left? Look at the shirt on portrait 1. (Do this even if person 1 is crossed out.) Cross out each OTHER person who has that same shirt. Never cross out person 1 in this step.
  5. Cross out anyone wearing square glasses.
CAREFUL A wrong pick raises the alarm. Check your paper one more time before you say "confirm".
PUZZLE 8

Debrief Tapes

Practices: Storytelling & sequencing · Describing & directing · Clarifying & repair

The Agent sees photo stills from a spy story. The story is mixed up. Ask about each still: What letter? Who is in it? Where are they? What small symbol is in the corner? The letters are just names. They do NOT show the order.

Match the corner symbol to the report part.
Corner markerReport entry
No small symbol in the corner. Just the person in a place.THE OPENING — who and where
A zigzag bolt in the corner. Something just happened!THE INCIDENT — what went wrong
A thought bubble. The person is making a plan.THE PLAN — what they decided to do
Two arrows. The person is doing the plan.THE ATTEMPT — what they did
A crack symbol. The plan hit trouble.THE COMPLICATION — the trouble on the way
A round seal. The story is over. Check = it worked. Dash = it did not.THE OUTCOME — how it ended

Linking words (harder tapes)

THEN = it comes next. SO = it happens because of the last part. BUT = trouble gets in the way.

Linking words. Find the two parts, say the word.

  1. Opening to Incident: say THEN.
  2. Incident to Plan: say SO.
  3. Incident to Attempt: say SO.
  4. Plan to Attempt: say THEN.
  5. Attempt to Complication: say BUT.
  6. Complication to Outcome: say SO.
  7. Attempt to Outcome: say SO.

Tell the story

  1. When all the stills are in order, the Agent tells the whole story out loud.
  2. Listen. Is every part there? Is it in order?
  3. If a part is missing, ask for it again.
  4. Then the Agent presses “Tape recorded”.
TIP Not sure which part a still is? Ask about the corner symbol again. Asking is free!
