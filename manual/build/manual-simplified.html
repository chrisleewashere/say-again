Handler Briefing

You are the Handler. Your partner is the Agent. The Agent sees the puzzle. You see the rules. Talk to win!

  1. Ask: "What puzzle do you see?"
  2. Find that puzzle in this book.
  3. Ask about colors, shapes, and letters.
  4. Say one step at a time.
  5. Not sure? Ask again. Asking is always safe.

The app calls easy puzzles Rookie, medium Agent, and hard Mastermind. Some rules only appear on harder missions — those parts are labeled.

TIP Rule lists always go in order from the top. Use the FIRST rule that matches, then stop.

PUZZLE 1

Laser Grid Bypass

Practices: Following directions · Describing & directing · Clarifying & repair

The Agent sees wires. Each wire has a color, a pattern, and one letter. First ask: "How many wires?" Then use that list below. Go rule by rule. Stop at the first rule that fits.

  • Wire 1 is at the top.
  • Wire numbers do not change.
  • Ask about colors, patterns, and letters.

4 wires

Use the first rule that fits.

  1. If only one wire is striped, cut that striped wire.
  2. If you see zero crimson wires, cut wire number 2.
  3. If the last wire is teal, cut the last wire.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut wire number 3.

5 wires

Use the first rule that fits.

  1. If only one wire is dotty, cut that dotty wire.
  2. If the first wire is zigzag, cut wire number 4.
  3. If you count 2 or more violet wires, cut the lowest violet wire.
  4. If no wire has a vowel letter (A, E, U), cut wire number 1.
  5. If no rule above worked, cut the first wire with a vowel letter.

6 wires

Use the first rule that fits.

  1. If there is only one silver wire, cut the first silver wire.
  2. If zero wires are plain, cut wire number 5.
  3. If the last wire is amber, cut wire number 2.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut the last wire.

Second cut (hard missions only)

Hard missions need two cuts. After cut one, use this list. If that wire is already cut, cut the lowest wire that is left.

Use the first rule that fits.

  1. If your first cut was a striped wire, cut the last wire.
  2. If your first cut was silver, cut wire number 1.
  3. If your first cut had a vowel letter, cut wire number 3.
  4. If no rule above worked, cut wire number 4.
TIP Not sure? Ask the Agent to say the wire again. Asking is smart!
