Print me. Hand me to the Handler. Never show the Agent.

Handler Briefing

You are the Handler. Your partner is the Agent. The Agent sees the puzzle. You see the rules. Talk to win!

  1. Ask: "What puzzle do you see?"
  2. Find that puzzle in this book.
  3. Ask about colors, shapes, and letters.
  4. Say one step at a time.
  5. Not sure? Ask again. Asking is always safe.

The app calls easy puzzles Rookie, medium Agent, and hard Mastermind. Some rules only appear on harder missions — those parts are labeled.

TIP Rule lists always go in order from the top. Use the FIRST rule that matches, then stop.

PUZZLE 1

Laser Grid Bypass

Practices: Following directions · Describing & directing · Clarifying & repair

The Agent sees wires. Each wire has a color, a pattern, and one letter. First ask: "How many wires?" Then use that list below. Go rule by rule. Stop at the first rule that fits.

  • Wire 1 is at the top.
  • Wire numbers do not change.
  • Ask about colors, patterns, and letters.

4 wires

Use the first rule that fits.

  1. If only one wire is striped, cut that striped wire.
  2. If you see zero crimson wires, cut wire number 2.
  3. If the last wire is teal, cut the last wire.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut wire number 3.

5 wires

Use the first rule that fits.

  1. If only one wire is dotty, cut that dotty wire.
  2. If the first wire is zigzag, cut wire number 4.
  3. If you count 2 or more violet wires, cut the lowest violet wire.
  4. If no wire has a vowel letter (A, E, U), cut wire number 1.
  5. If no rule above worked, cut the first wire with a vowel letter.

6 wires

Use the first rule that fits.

  1. If there is only one silver wire, cut the first silver wire.
  2. If zero wires are plain, cut wire number 5.
  3. If the last wire is amber, cut wire number 2.
  4. If any wire has a vowel letter (A, E, U), cut the first wire with a vowel letter.
  5. If no rule above worked, cut the last wire.

Second cut (hard missions only)

Hard missions need two cuts. After cut one, use this list. If that wire is already cut, cut the lowest wire that is left.

Use the first rule that fits.

  1. If your first cut was a striped wire, cut the last wire.
  2. If your first cut was silver, cut wire number 1.
  3. If your first cut had a vowel letter, cut wire number 3.
  4. If no rule above worked, cut wire number 4.
TIP Not sure? Ask the Agent to say the wire again. Asking is smart!
PUZZLE 2

Crack the Safe

Practices: Describing & directing · Vocabulary & categories · Clarifying & repair

The Agent sees gems in a row. Under the gems is a number pad. Each gem has a shape, a mark, and a size tag (S or L). Ask about one gem at a time: "What shape? What mark? S or L?" Use the table to get each number. Then tell the Agent the code.

  • Gems go left to right. Gem 1 is on the left.
  • Every gem has a tag: S or L.
  • Ask about shape, mark, and tag.

Step 1 — Find the number

Find the shape. Then find the mark. That is the number.

Step 2 — Check the size tag

Do this for every gem.

  1. Large gem (tag L)? Add 2. After 9 you start over at 0: 8 turns into 0, 9 turns into 1. A small gem (tag S) does not change.

Step 3 — Only for 4 gems

Only do this if there are 4 gems. Do it after you have all the numbers. Use the first rule that fits.

Use the first rule that fits.

  1. If any two gems are the same shape, say the code backwards (last number first).
  2. If no rule above worked, say the code just as it is.
  1. Ask: "How many gems?"
  2. Ask about each gem: shape, mark, tag.
  3. Turn each gem into a number.
  4. 4 gems? Do Step 3.
  5. Say the code. The Agent types it and presses ENTER.
TIP Not sure about a gem? Ask again. Asking is smart! Have the Agent read the code back before ENTER.
PUZZLE 3

Code Room

Practices: Vocabulary & categories · Describing & directing · Clarifying & repair

The Agent sees keys with words on them. Each word fits one list below. Ask the Agent to read each word. Find each word's list. Then say which key to press. List 1 words go first. Locked keys show a number and a check mark.

  1. Agent reads every word out loud.
  2. Find each word in one list below.
  3. Say the words in list order, one at a time.

Press order.

  1. 1. Animals words go first.
  2. 2. Tools words go next.
  3. 3. Food words go next.
  4. 4. Clothes words go next.
  5. 5. Rides words go next.
  6. 6. Weather words go next.
  7. 7. School stuff words go next.
  8. 8. Feelings words go next.
  9. Two words from the same list? Press the word that comes first in ABC order.
TIP A word could fit two lists? Only one list really has it. Not sure? Ask the Agent to spell the word. Asking is smart!

PUZZLE 4

Password Intercept

Practices: Vocabulary & categories · Following directions · Clarifying & repair

The Agent sees a card number and five words. You have the card list. Ask: "What card number?" Find that card below. Read the rule and the clue out loud. The Agent picks the one word that fits.

  1. Ask: "What card number?"
  2. Say the number back. Wait for "yes".
  3. Find the card in the list. Read it out loud, like: "Card 15. Find the word that is the OPPOSITE of "ancient"."
  4. Ask the Agent to read all five words.
  5. Pick the one word together. The Agent taps it.
TIP Say the card number back before you decode. Not sure? Ask the Agent to say it again. Asking is smart!

PUZZLE 5

Alarm Bypass

Practices: Following directions · Describing & directing

The Agent sees four buttons with shapes and letters: Moon (C), Key (K), Bolt (B), Eye (E). The panel flashes some shapes. The Agent can replay the flash any time. Ask for the model code on the panel. Ask for the round number. The Agent says the flashed shapes. You use the right table below. It tells you which buttons to press.

TIP Have the Agent read the whole signal first. Then translate one shape at a time. Not sure? Ask for the letter!
  1. Ask: "What is the model code?"
  2. Ask: "What round is it?"
  3. The Agent says the flashed shapes, in order.
  4. Use that round’s table. SEE is what flashed. PRESS is the answer.
  5. Say the presses in order. The Agent presses them.
